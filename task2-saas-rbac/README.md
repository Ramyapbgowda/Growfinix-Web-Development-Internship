# Task 2: SaaS Multi-Tenant Architecture with RBAC

## Tech Stack
- Next.js
- Node.js
- PostgreSQL
- Middleware

## Description
Build a platform that supports multiple different organizations (tenants). Implement strict Role-Based Access Control (RBAC) so Super Admins, Managers, and Users see completely different dashboards and have different backend permissions.

## Features
- Multi-Tenant Architecture
- Role-Based Access Control (RBAC)
- Super Admin Dashboard
- Manager Dashboard
- User Dashboard
- Authentication & Authorization
- Project Management
